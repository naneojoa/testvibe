# REQ-001: 요구사항부터 PR까지 연결되는 개발 체계

## 출처

2026-10-26 사용자 요청. 2026-10-27 실제 작업 위치를 `C:\workspace\bbs-example\board`로 정정했다.

## 원문 요약

기존 Markdown을 체계화하고 고객 요구사항 분석, PRD, 테스트·검증, 하네스, 기능 브랜치 커밋과 `main` 대상 PR까지 연결한다. 각 폴더의 기능과 문서 추가 이유를 설명한다.

## 확정 사항

- 작업 저장소는 `board` 디렉토리다.
- 기능 브랜치를 사용하고 `main`에 PR을 요청한다.
- 민감정보와 보안정보는 Git에 올리지 않는다.

## 미해결 사항

- 고객에게 확인할 게시판 제품 정책은 `product/questions.md`에서 관리한다.
- GitHub push 계정의 저장소 쓰기 권한이 필요하다.
